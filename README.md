# 🌐 Portfólio de Luan Freitas

Site estático do portfólio de Luan Freitas, Cientista de Dados (NLP, LLMs e MLOps), publicado em <https://luanfreitas5.github.io/>.

## 📁 Estrutura

```
index.html          # Página única (pt-BR)
assets/style.css    # Estilos, com tema claro e escuro
assets/main.js      # Alternância de tema
assets/favicon.svg  # Ícone
.nojekyll           # Publica os arquivos como estão, sem Jekyll
```

## 🚀 Como visualizar localmente

```bash
python -m http.server 8000
# abra http://localhost:8000
```

## 📤 Como publicar

O repositório se chama `luanfreitas5.github.io`, então o GitHub Pages serve a branch `main` na raiz.
Em **Settings → Pages**, escolha **Deploy from a branch**, branch `main`, pasta `/ (root)`.

## ✏️ Como atualizar o conteúdo

Todo o texto está em `index.html`. As métricas dos projetos vêm dos READMEs dos repositórios; atualize-as junto com eles.
